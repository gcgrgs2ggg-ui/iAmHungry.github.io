# 《一碗海风的迁徙》· 网页版电子书

可画（Canva）竖版绘本 → 仿真翻页网页版电子书的成品站。**88 页**，A4 竖版比例（1:√2）。

- **PC**：两两对开，翻单张竖版页（真书手感，拖页角）
- **手机**：单页竖版，一屏一页
- **左侧目录**：六地 · 三十三味，两级可折叠，点击直达
- **翻页音效**：纸张摩擦声，默认开启，可一键关闭
- **零外链**：翻页库与字体全部本地，不依赖任何 CDN

---

## 一、上传这些（其余不用传）

新建 GitHub 仓库后，把下面 6 项拖进去，**这 6 项是线上必需的**：

```
index.html
style.20261124.css
app.20261124.js
.nojekyll              ← 隐藏文件，Finder 按 Cmd+Shift+. 才看得见
assets/                ← 33 MB：88×2 张页面、manifest、目录数据、分享图、图标
vendor/                ← page-flip 库（MIT），48 KB
```

共 **188 个文件**（不含 README）。GitHub 网页上传**单次上限 100 个**，所以 `assets/pages/hi` 与 `assets/pages/lo`
要各分两次拖（`page-00~43` / `page-44~87`），或者直接用 GitHub Desktop 一次推完。

⚠️ `assets/编辑汇总版.docx`（16.9 MB）不是站点文件，**上传时不要带上**。
`tools/`、`README.md` 传不传都不影响打开；原始 PNG（约 300 MB）不要传。

## 二、部署（GitHub Pages）

1. 新建仓库，**Public**，不要勾 README / .gitignore
2. 文件拖进仓库根目录 → Commit
3. Settings → Pages → Source 选 `Deploy from a branch`，Branch `main`、目录 `/ (root)` → Save
4. 等 1–2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`

> `.nojekyll` 必须传。它是个空文件，用来阻止 Jekyll 过滤以下划线开头的路径。

## 三、上线后唯一要改的一处

`index.html` 里这两行还是占位符（微信/QQ 抓取器不执行 JS，分享卡片必须静态写死）：

```html
<meta property="og:url" content="https://<用户名>.github.io/<仓库名>/">
<meta property="og:image" content="https://<用户名>.github.io/<仓库名>/assets/og.20261124.jpg">
```

把 `<用户名>` / `<仓库名>` 换成实际的。不改也能正常看书，只是分享出去没有缩略图。

## 四、本地预览

不能直接双击 `index.html`（`file://` 下浏览器会拦截 canvas 取图）。在**本文件夹内**开终端：

```bash
cd ~/Desktop/一碗海风的迁徙-电子书
python3 -m http.server 8010
```

浏览器打开 `http://127.0.0.1:8010/`。手机同 Wi-Fi 访问 `http://<电脑局域网IP>:8010/`
（`ipconfig getifaddr en0` 查 IP）。

开发自查参数：

| 参数 | 作用 |
|---|---|
| `#p=12` | 直达第 13 页 |
| `?open=toc` | 直接展开左侧目录 |
| `?open=grid` | 打开 88 张缩略图网格 |
| `?open=zoom` | 打开单页放大层 |
| `?diag=1` | 把实际视口/书的尺寸写进标题 |
| `?open=toc&qa=10` | 真实点击第 11 个菜品，验证直达链路 |

## 七、翻页音效与中缝处理

**音效**：用 Web Audio API 实时合成（滤波白噪声 + 快速起音/衰减包络，约 0.4 秒），
**没有任何音频文件**，不增加上传数量、不产生额外请求。挂在翻页库的 `changeState`
状态机上，只在动画开始（`flipping`）时响一次，所以拖页角、点按钮、键盘、目录跳转
的音效完全同步；连续快翻有 240 ms 节流，不会叠成爆音。

工具栏「音效 开 / 音效 关」可切换，状态存在 `localStorage`，下次打开沿用。
iOS Safari 需要用户手势才能启动音频，首次翻页本身就是手势，因此不受自动播放策略影响。

**中缝**：已按需求**取消两跨页交界处的静态书脊阴影**——删掉了页面内侧的 `.gutter`
渐变，也去掉了书壳背景里的中缝黑带，两页并排时是干净衔接。
**翻页动画本身的动态阴影保留**（`drawShadow: true`），这是"推真翻页"的一部分。

## 八、要重新生成素材时

把可画导出的全部 PNG 解压进 `raw/`（或直接用 `BOOK_RAW=<目录>` 指定），然后：

```bash
python3 tools/build_assets.py
```

脚本会：按页序排序（认「封面」「空白页」「空白页 (2)＝封底」）、统一裁成同一比例、
**全量重写 88×2 张 WebP**、生成 LQIP、重写 `assets/manifest.v1.json`、
重建分享图与图标。它不做增量，每次都整本重编码。

书名 / 作者 / 简介写在 `tools/book.json`，改完重跑即可同步到页面标题与分享卡片。
改画布比例时同步改 `build_assets.py` 顶部的 `HI_W/HI_H/LO_W/LO_H`（当前 1600×2263 = A4 竖版）。

## 九、三条固定规则（不是 bug）

1. **封面、封底不居中**：硬壳页固定占右半（封面）/ 左半（封底），空出的半边是书壳材质。
   强行居中会和库的坐标计算打架，翻页时位置会漂。
2. **总页数必须是偶数**：`showCover` 模式下奇数页会让封底被挤进最后一个对开，翻到末页报错。
3. **手机和 PC 是同一个翻页实例自动切换**，不销毁不重建，横竖屏来回转不会丢页码、
   不会出现半张对开。

## 十一、容易踩的坑

| 坑 | 说明 |
|---|---|
| 直接双击 html | `file://` 下取图失败，必须用 `http.server` |
| 忘了 `.nojekyll` | 带下划线的路径会被 Jekyll 忽略 |
| 网页上传超 100 个 | 单次拖拽上限，分批传或改用 GitHub Desktop |
| 把 `assets/编辑汇总版.docx` 传上去 | 不是站点文件，白占 17 MB |
| 用 `?v=123` 做缓存刷新 | GitHub Pages 的 CDN 会忽略查询串，改文件名才可靠 |
| 改了图片但没改名 | CDN 缓存最长 10 分钟，等一会儿或改文件名 |
| 素材用 PNG 直接上传 | 33 MB → 300 MB，仓库会变很卡 |
| 改动页数后没重跑脚本 | `manifest` 与 DOM 页数不一致会直接报错 |
| 替换了页面但没改 `toc.json` | 目录会跳到旧页码，按第五节重跑 `gen_toc.py` |
